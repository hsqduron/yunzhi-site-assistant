# 云指建站常见问题

本文汇总建站过程中高频出现的连接、模板、数据、表单、页面保存和排障问题。执行具体任务时，先遵循 `SKILL.md` 的强制规则，再按问题类型查阅本文和对应的详细参考文档。

## 一、MCP 连接

### 1. 为什么调用 MCP 前必须提供地址和 Token？

MCP 地址用于确定目标站点，Bearer Token 用于身份认证。缺少任一项都不能确认操作对象和权限。

### 2. MCP 地址和 Token 只提供一个怎么办？

只向用户索取缺失的那一项。信息完整前不得调用任何 MCP 工具，包括 `test`。

### 3. 切换站点时为什么要重新提供地址和 Token？

不同站点的 MCP 地址、Token 和数据 ID 都不同，不能混用上一站点的连接信息。

### 4. MCP 返回 `401` 或 `Unauthorized` 怎么办？

提示用户重新提供有效 Token，不回显旧 Token，也不要继续尝试写入操作。

### 5. Token 是否作为工具参数传入？

不需要。Token 由 MCP 客户端通过 `Authorization: Bearer <token>` 请求头传入。

### 6. MCP 无法连接时还能生成代码吗？

可以，但必须明确处于离线模式，且不能假装已经读取或修改站点数据。

### 7. 如何确认当前操作的是正确站点？

连接后先调用 `test`，再查询页面、分类或内容，并在写入前向用户展示目标信息。

## 二、Twig 与模板

### 8. 为什么 Twig 控制语句不能写在 HTML 标签属性中？

可视化编辑器会解析 HTML，属性中混入 `{% if %}`、`{% for %}` 可能导致页面结构失效。

### 9. 为什么 Twig 标签不能放在 `<html>` 之前？

编辑器可能过滤页面开头的 Twig 内容，导致模板逻辑丢失。

### 10. `<title>` 中可以使用 Twig 条件语句吗？

不可以。应在外部准备变量后，在 `<title>` 中输出结果。

### 11. 可以使用 Twig 1.3 之外的新语法吗？

不可以。页面必须遵循系统支持的 Twig 1.3 语法。

### 12. `|default` 为什么不能多层嵌套？

系统对嵌套 `default` 支持有限，复杂嵌套可能解析失败，应提前分步设置变量。

### 13. 什么时候使用 `|raw`？

只有内容来源可信且确实需要渲染 HTML 时使用，普通文本默认保持转义。

### 14. 页面中的站点域名应该如何处理？

拼接完整域名时使用 `FnGetHost($type)`；获取当前完整访问地址时使用 `FnGetCurrentUrl()`。

### 15. 站内链接需要拼接完整域名吗？

不需要。本站内部链接优先使用相对链接和 `FnRewrite(...)`。

## 三、动态数据与链接

### 16. 公司名称、电话、邮箱从哪里获取？

优先使用 `DataTag.sys`，避免在页面源码中硬编码。

### 17. 产品列表和详情如何获取？

使用 `FnGetProCls`、`FnGetProList` 和 `FnGetOnePro`。

### 18. 文章列表和详情如何获取？

使用 `FnGetNewsCls`、`FnGetNewsList` 和 `FnGetOneNews`。

### 19. FAQ 内容为什么不能硬编码？

FAQ 属于后台可维护内容，应使用 `FnGetFaqClassList` 和 `FnGetFaqList` 动态获取。

### 20. 产品或文章列表中的图片需要加详情链接吗？

需要。图片、名称、标题等主要可视元素都应链接到对应详情页。

### 21. 只给“查看详情”按钮加链接可以吗？

不可以，不能只依赖单独的“查看详情”或“更多”按钮。

### 22. 详情链接如何生成？

使用系统稳定 ID，并通过 `FnRewrite(...)` 生成，不要手写 CMS 路由。

### 23. Twig 分页和 MCP 分页参数一样吗？

不一样。Twig 通常使用 `offset/pagesize`，MCP 使用 `page/pageSize`，不能混用。

### 24. 产品价格为空或为 0 怎么显示？

隐藏价格，或显示“面议”，不要输出无意义的 0。

### 25. 产品详情内容可能是什么格式？

`Content` 可能是 JSON 数组，也可能是 HTML 字符串，需要根据实际返回类型处理。

## 四、公共页头页尾

### 26. 什么情况下应该制作公共页头页尾？

多个页面使用相同头部和尾部时，应抽取为公共片段，减少重复代码和维护成本。

### 27. 公共页头页尾可以包含 `<html>`、`<head>`、`<body>` 吗？

不可以，只保存可嵌入的内容片段。

### 28. 公共页头页尾必须自带 CSS 和 JavaScript 吗？

必须。片段应自包含，不能依赖宿主页是否引入 CSS 或脚本。

### 29. 如何保存公共页头页尾？

使用 `save_ai_page`，页头名称和 URL 固定为 `common_top`、`common_top.html`；页尾对应为 `common_foot`、`common_foot.html`。

### 30. 如何在页面中引用公共片段？

获取保存结果中的 `codePath`，使用 `{{FnInclude($codePath, '包含备注')}}` 引入。

### 31. 公共片段为什么在移动端显示异常？

检查片段是否自带完整 CSS 和所有必要的 `@media` 响应式断点。

## 五、自定义表单

### 32. 什么情况下使用系统动态表单？

需要收集姓名、电话、邮箱、留言、预约、报名、询价、文件等用户输入时优先使用。

### 33. 为什么不能直接写静态提交接口？

系统动态表单已经包含字段配置、校验、上传、验证码和提交协议，独立接口容易与后台不兼容。

### 34. 如何选择普通自定义表单？

先调用 `list_custom_form`，展示表单 ID 和名称，让用户选择后再调用 `FnGetCustomForm(表单ID)`。

### 35. 可以直接猜测表单 ID 吗？

不可以。表单 ID 必须来自当前站点查询结果或用户明确确认。

### 36. 表单示例中的哪些内容不能删除？

隐藏字段、`action`、`enctype`、字段元数据、校验脚本、AJAX 提交、上传、短信和验证码逻辑。

### 37. 文件上传为什么需要 `enctype`？

没有 `multipart/form-data`，浏览器不会正确提交文件数据。

### 38. 文件上传成功后为什么还要写隐藏字段？

文件通常先上传，后端返回文件路径；正式提交时通过隐藏字段传递该路径。

### 39. 单文件和多文件上传有什么区别？

多文件上传使用 `uploadfiles` 接口、数组参数，并必须提交 `count`。

### 40. 多个表单如何避免冲突？

每个表单使用独立的样式类、校验选择器、变量和事件处理逻辑。

## 六、产品询盘

### 41. 产品询盘和普通自定义表单有什么区别？

产品询盘在动态表单基础上增加产品列表、数量管理和 `EnquiryProduct` 业务字段。

### 42. 为什么必须调用 `get_enquiry_form_id`？

不同站点的询盘表单 ID 不同，必须获取当前站点真实 ID，不能使用示例值。

### 43. 首次调用 `get_enquiry_form_id` 会产生写入吗？

可能。如果站点没有有效询盘表单，工具可能自动初始化默认表单和字段，因此调用前要说明副作用并确认。

### 44. `EnquiryProduct` 有什么作用？

用于提交访客选择的产品及数量，是产品询盘的业务级必填字段。

### 45. 为什么提交前要重新同步 `EnquiryProduct`？

用户可能修改数量或删除产品，提交时必须重新读取询盘车并序列化。

### 46. 询盘产品数据从哪里获取？

使用系统产品数据函数获取，不要长期硬编码产品名称、图片或参数。

### 47. 联系我们表单和询盘表单可以使用同一个 ID 吗？

不可以，两个业务场景必须使用不同表单。

### 48. 询盘产品重复时怎么办？

使用产品 ID 去重，并统一转换为字符串后比较。

### 49. 上传文件后为什么不能再次提交 `file input`？

文件已提前上传并写入隐藏字段，正式提交只需提交隐藏字段，避免重复上传。

## 七、在线查询

### 50. `get_online_query_list` 和 `FnGetOnlineQuery` 有什么区别？

前者用于 MCP 查询后台配置列表，后者用于页面模板读取指定查询配置并渲染查询表单。

### 51. 在线查询推荐使用哪种模式？

推荐 AJAX 模式，由前端接收结果并渲染，不刷新整个页面。

### 52. 什么时候使用同步提交模式？

需要表单提交后由服务端重新渲染当前页面时使用。

### 53. 为什么首次打开页面不能直接调用 `FnGetOnlineQueryResult`？

它依赖 POST 参数、图形验证码和查询条件，首次没有有效 POST 数据时可能返回错误或中断渲染。

### 54. 查询结果为空或验证码错误怎么办？

检查查询 ID、状态、时间范围、POST 字段、图形验证码和短信验证码。

### 55. AJAX 返回 HTML 而不是 JSON 怎么办？

检查 `action`、`QueryID`、验证码字段和接口地址，不要把错误页面当作 JSON 解析。

## 八、内容、资源与页面操作

### 56. 新增文章前为什么要查询分类？

文章分类 ID 必须属于当前站点，避免内容归类错误。

### 57. 新增文章默认发布吗？

工具默认可能立即发布；用户未明确要求发布时应使用 `status=0` 保存为草稿。

### 58. 修改文章前为什么先调用 `get_news_info`？

需要读取当前内容，避免覆盖未知字段，并确保提交的是实际变更。

### 59. 新增产品支持 SKU 和规格吗？

当前精简产品工具不支持 SKU、规格等高级字段。

### 60. 产品主图应该如何上传？

使用 `upload_product_image`，并原样传入返回的 `fileName` 和 `SmallFileName`。

### 61. 普通图片和文件使用哪个工具？

使用 `upload_file`；产品主图使用 `upload_product_image`。

### 62. 上传工具可以同时传 Base64 和远程 URL 吗？

不可以，每次只能提供一种来源。

### 63. 保存页面前为什么要调用 `list_page`？

用于判断是新建还是更新，并确认当前页面 ID、名称和 URL。

### 64. 修改已有 AI 页面前必须做什么？

先 `list_page` 查找页面，再用 `get_page_info` 读取 `SourceCode`，不能盲目覆盖。

### 65. 页面不是 AI 页面怎么办？

不能使用 `save_ai_page` 覆盖，应说明限制并改用合适的编辑方式。

### 66. 删除页面后能恢复吗？

不能。`del_page` 是物理删除，并会清理相关模块、样式、权限、URL、文件和缓存。

### 67. 设置首页或修改 URL 需要确认吗？

需要。这些操作会影响站点入口或已有访问路径，必须单独确认。

## 九、JSON-LD 与 SEO

### 68. 哪些页面应该添加 JSON-LD？

产品详情、文章详情、FAQ、公司信息和需要面包屑的页面，应根据实际内容添加。

### 69. JSON-LD 数据从哪里获取？

优先使用页面实际渲染内容或系统返回的 `JsonLD` 字段。

### 70. 产品 JSON-LD 为什么没有价格？

本站产品按非商品类约定处理，不生成 `offers`、`price`、库存等交易字段。

### 71. 产品评分是否显示在页面上？

不显示。评分仅作为结构化数据补充，不得伪装成真实站内评价。

### 72. 产品详情页 TDK 如何生成？

`title` 使用 `SeoTitle`，为空时使用产品名称；`description` 使用 `SeoDesc`，为空时使用 `ProDesc`；`keywords` 使用 `ProKeyword`。

### 73. 新闻详情页 TDK 如何生成？

`title` 使用 `Title`；`description` 使用 `ArtDesc`，为空时使用 `Descriptor`；`keywords` 使用 `ArtKeyword`。

## 十、SQLite 与搬站

### 74. 什么情况下使用 SQLite？

仅用于系统现有功能无法满足的小型扩展，页面、产品、文章、表单和在线查询应优先使用系统功能。

### 75. SQLite 数据库名称有什么限制？

只能使用字母、数字、下划线及 `.db` 或 `.sqlite` 后缀。

### 76. `query_sqlite` 和 `execute_sqlite` 有什么区别？

`query_sqlite` 只允许查询；`execute_sqlite` 用于新增、修改、删除或建表等非查询 SQL。

### 77. 为什么 SQL 必须使用参数绑定？

防止 SQL 注入，禁止把用户输入直接拼接进 SQL。

### 78. SQLite 查询为什么最多返回 1000 行？

系统对查询结果有上限，大数据量应使用 SQL 自行分页。

### 79. 搬站时哪些内容不能采集？

不采集登录后内容、用户数据、支付流程、追踪脚本、第三方密钥和其他敏感信息。

### 80. 搬站时为什么先上传素材再入库？

内容记录需要引用目标站点中的图片或文件，必须先取得上传工具返回的地址或文件名。

### 81. 源站表单可以直接复制吗？

不可以。应使用目标站点的动态表单，不复制源站提交接口或后台代码。

### 82. 批量导入失败会自动回滚吗？

不会。失败前已写入的页面和资源会保留，执行前必须向用户说明。
